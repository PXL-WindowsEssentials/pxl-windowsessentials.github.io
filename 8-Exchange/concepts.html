    Microsoft 365 - Exchange Online

    1. Inleiding

    1.1. Wat is Exchange Online?

    Exchange Online is de cloudversie van Microsoft Exchange Server en maakt deel uit van Microsoft 365 (voorheen Office 365). Het is een e-mail- en agendaoplossing die in de Microsoft-cloud wordt gehost.

    1.2. Belangrijkste functies van Exchange Online

    • 📧 E-mail: professionele e-mail met je eigen domein (bv. jouwnaam@bedrijf.com).
    • 📅 Agenda: gedeelde agenda's voor vergaderingen, afspraken en beschikbaarheid.
    • 👥 Contacten: centrale opslag van contacten, gesynchroniseerd over toestellen heen.
    • 📁 Mailboxbeheer: grote mailboxen (50 GB of meer) met automatische back-ups.
    • 📲 Overal toegankelijk: gebruik Outlook (desktop), Outlook Web App (browser) of mobiele apps.
    • 🔐 Beveiliging: antivirus, antispam, gegevensencryptie en multi-factor authentication.
    • 🧰 Beheer: centraal beheer via het Microsoft 365 Admin Center of PowerShell.

    1.3. Verschillen met Exchange On-Premises

    Exchange Online Exchange Server (On-Premises)
    Door Microsoft in de cloud gehost Gehost op servers die eigendom zijn van het bedrijf
    Geen onderhoud van hardware/software Vereist serverbeheer en onderhoud
    Maandelijks abonnement (per gebruiker) Eenmalige investering + licenties
    Schaalbaar en flexibel Minder flexibel zonder extra investering

    2. Microsoft 365 Admin Center

    Je kan het admin center bereiken via https://admin.exchange.microsoft.com. In het linkermenu zie je verschillende opties. In deze cursus gebruiken we vooral Recipients:

    • Mailboxes → gebruikersmailboxen
    • Groups → gedeelde groepsmailboxen
    • Resources → ruimtes en toestellen
    • Contacts → externe contacten

    3. Gebruikers en mailboxen beheren

    3.1. Types mailboxen

    Type Beschrijving Voorbeeld
    User mailbox Persoonlijke mailbox gekoppeld aan één gebruiker. Vereist een licentie. jan.peeters@bedrijf.com
    Shared mailbox of Group Gedeeld door meerdere gebruikers. Geen directe aanmelding. info@bedrijf.com, hr@bedrijf.com
    Resource mailbox Om resources zoals ruimtes of apparatuur te reserveren. room1@bedrijf.com, projector@bedrijf.com
    Mail contact Bewaart externe contacten. Geen mailbox. naam@gmail.com

    3.2. Mailboxen aanmaken en toewijzen

    • User mailbox
      • Wordt automatisch aangemaakt wanneer je een gebruiker met licentie toevoegt.
      • Kan aangemaakt worden in: Microsoft 365 Admin Center (GUI) of PowerShell (New-Mailbox).
    • Shared mailbox
      • Aanmaken in: Microsoft 365 Admin Center → Shared mailboxes, of PowerShell (New-Mailbox -Shared).
      • Machtigingen toewijzen: "Full Access" en/of "Send As".
    • Resource mailbox
      • Aanmaken in het Exchange Admin Center (EAC) of PowerShell.
      • Types: Room mailbox (vergaderruimte) of Equipment mailbox.
    • Group email
      • Aanmaken in EAC of PowerShell.
      • Geen mailbox, stuurt e-mails enkel door naar de leden.
    • Mail Contact
      • Aanmaken in EAC of PowerShell.
      • Wordt enkel gebruikt om externe contactgegevens in het adresboek op te slaan.

    3.3. Mailboxeigenschappen en -machtigingen

    Voorbeelden van mailboxeigenschappen:

    • Display name
    • E-mailadres / aliassen
    • Opslagquota
    • Archivering aan/uit

    Mailboxmachtigingen:

    • Full Access → de gebruiker kan de mailbox openen en beheren.
    • Send As → de gebruiker kan verzenden alsof hij de mailbox is.
    • Send on Behalf → de gebruiker verzendt namens de mailbox.

    Je kan deze instellen in:

    • Microsoft 365 Admin Center
    • Exchange Admin Center (EAC)
