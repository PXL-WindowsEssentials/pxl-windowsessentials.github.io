Windows 11 installeren in VMware Workstation¶

In deze handleiding maak je een nieuwe virtuele Windows 11-machine aan in VMware Workstation Pro en installeer je Windows 11 erop. Je hebt hiervoor de Windows 11 ISO nodig die je eerder downloadde. Deze virtuele machine gebruik je in de volgende labo's.

1. Een nieuwe virtuele machine aanmaken in VMware¶

1.1. New Virtual Machine¶

  • Open VMware Workstation.
  • Klik linksboven op het menu "File".
  • Selecteer "New Virtual Machine".

1.2. Wizard voor virtuele machines, deel 1:¶

In de New Virtual Machine Wizard:

  • Selecteer "Custom: advanced" en klik op Next. Zo kan je alle instellingen zelf kiezen.
  • Selecteer "Hardware: VMware Workstation 17.5 or later" (afhankelijk van je versie van VMware Workstation) en klik op Next.

1.3. Wizard voor virtuele machines, deel 2:¶

In de New Virtual Machine Wizard:

  • Kies "Installer disc image file (iso)", klik op Browse en selecteer de Windows 11 ISO die je eerder downloadde (meestal in je map Downloads). Onder de bestandsnaam verschijnt "Windows 11 x64 detected". Klik op Next.

  • Geef de virtuele machine een duidelijke naam. De locatie is de map C:\Virtual Machines\... die je bij de voorkeuren hebt ingesteld. Klik op Next.

  • Kies bij Encryption Information de optie "Only the files needed to support a TPM are encrypted".

  • Klik op "Generate" om een encryptiewachtwoord aan te maken. Windows 11 vereist een TPM, en VMware simuleert die met een versleuteld bestand. Je kan ook zelf een wachtwoord ingeven. Bewaar het goed: je hebt het nodig als je de virtuele machine verplaatst naar een ander toestel of een andere locatie. Laat "Remember the password on this machine in Credential Manager" aangevinkt en klik op Next.

1.4. Wizard voor virtuele machines, deel 3:¶

In de New Virtual Machine Wizard:

  • Selecteer bij Firmware type de optie UEFI (laat Secure Boot uitgevinkt) en klik op Next.
  • Processors: laat de standaardwaarden staan.
  • Memory: 4096 MB (standaard).
  • Network connection: kies network address translation (NAT). Je virtuele machine deelt dan het internet van je laptop.
  • SCSI Controller: LSI Logic SAS.

1.5. Wizard voor virtuele machines, deel 4:¶

In de New Virtual Machine Wizard:

  • Virtual Disk Type: NVMe
  • Disk: Create a new virtual disk
  • Maximum Disk Size: 64 GB. De virtuele machine neemt niet meteen 64 GB in op je schijf, maar groeit mee tot dat maximum.
  • Split virtual disk into multiple files en Allocate all disk space now (uitgevinkt): laat de standaardwaarden staan.
  • Disk File Name: laat de standaardwaarden staan.
  • Controleer het overzicht Ready to Create Virtual Machine. Laat Power on this virtual machine after creation uitgevinkt.
  • Klik op Finish.

De virtuele machine is nu aangemaakt.

1.6. De virtuele machine starten¶

  • Start de virtuele machine door te klikken op "Power on this virtual machine".
  • Zodra het VMware-logo verschijnt, klik je één keer ergens in het venster van de virtuele machine. Zo krijgt de virtuele machine je toetsenbord.
  • Wanneer je de melding "Press any key to boot from CD or DVD" ziet, druk je snel op een toets. Doe je dat niet op tijd, dan start de machine niet vanaf de ISO.
  • Na enkele seconden zie je het Windows-logo.

Zie je een melding "EFI Network..." of een blauw scherm met "Boot normally", dan was je te laat met een toets in te drukken. Sluit de virtuele machine af en probeer opnieuw.

2. Windows Installer¶

2.1. Windows-wizard, deel 1¶

Kies in de Windows-installatiewizard de volgende opties:

  1. Selecteer de taal (Taal om te installeren), bijvoorbeeld Nederlands (Nederland).
  2. Selecteer de indeling voor tijd en valuta (bijvoorbeeld Nederlands (België)) en klik op Volgende.
  3. Selecteer "Windows 11 installation" en vink "I agree that everything will be deleted,..." aan. Dat kan geen kwaad: de virtuele schijf is nog leeg.
  4. Klik op "I don't have a product key". Voor labo's hoef je Windows niet te activeren.

2.2. Windows-wizard, deel 2¶

Kies in de Windows-installatiewizard de volgende opties:

  1. Selecteer de editie Windows 11 Education. Kies altijd Education, tenzij de instructies anders vermelden. Deze editie ligt het dichtst bij Enterprise en bevat de meeste functies.
  2. Accepteer de licentieovereenkomst om verder te gaan.
  3. Kies de installatielocatie: klik op "Next". Omdat dit een lege virtuele machine is, zie je maar één niet-gepartitioneerde schijf.
  4. Klik op "Install" om de installatie te starten.

2.3. Windows-installatie¶

De installatie duurt enkele minuten. De virtuele machine herstart daarbij een paar keer; dat is normaal.

3. Windows OOBE¶

Zodra Windows 11 is geïnstalleerd, start de Out of Box Experience (OOBE). Dat is het eerste configuratieproces van Windows, waarin je basisinstellingen zoals regio, gebruikersaccount en privacyvoorkeuren instelt.

3.1. OOBE, deel 1¶

Selecteer de volgende opties in de Windows OOBE:

  • Kies het land Belgium (België) en klik op Ja.
  • Kies je toetsenbordindeling (Belgian Period voor AZERTY, US voor QWERTY) en klik op Ja.
  • Klik bij de tweede toetsenbordindeling op Skip (Overslaan).

Windows zoekt nu naar updates. Dit kan enkele seconden tot enkele minuten duren.

3.2. OOBE, deel 2¶

In de volgende stappen maak je een lokale account aan in plaats van je aan te melden met een Microsoft-account. Zo heb je een eenvoudig lokaal beheerdersaccount om mee te starten. Later in de cursus voeg je de machine toe aan Entra ID en Intune.

  • Selecteer "Sign-in options" (Aanmeldingsopties).
  • Kies "Domain join instead" (In plaats daarvan deelnemen aan domein). Dit is de weg naar een lokale account zonder Microsoft-account.
  • Geef een gebruikersnaam in (gebruik je eigen voornaam) en klik op Volgende.
  • Geef een wachtwoord in en klik op Volgende. Herhaal het wachtwoord op de volgende pagina. Bewaar het veilig, bijvoorbeeld in een wachtwoordmanager.
  • Kies drie beveiligingsvragen en beantwoord ze met iets willekeurigs. Je gebruikt ze in deze cursus niet om je wachtwoord te herstellen.

3.3. OOBE, deel 3¶

In de volgende stappen van de Windows OOBE krijg je verschillende privacygerelateerde vragen. Antwoord op alle vragen “No” (Nee) en klik telkens op Accept (Accepteren). Bij de vraag over diagnostische gegevens ("Send diagnostic data to Microsoft") is er geen "Nee". Kies daar "Required only" (Alleen vereist).

3.4. OOBE, deel 4¶

Sinds Windows 11 versie 24H2 worden updates automatisch gedownload en geïnstalleerd tijdens de laatste stap van de OOBE. Dit kan 30 tot 45 minuten duren, afhankelijk van hoeveel updates er nog niet in de ISO zitten. Sluit de virtuele machine niet af tijdens dit proces.

4. Aanmelden¶

Wanneer de installatie klaar is, zie je het aanmeldscherm. Meld je aan met het wachtwoord dat je tijdens de OOBE hebt ingesteld.

De eerste keer aanmelden duurt ongeveer één minuut omdat het gebruikersprofiel wordt aangemaakt.

5. VMware Tools installeren¶

VMware Tools is software in de virtuele machine die zorgt voor een correcte schermresolutie, een vlotte muis en kopiëren en plakken tussen je laptop en de virtuele machine. Installeer ze daarom altijd.

5.1. De installatiewizard van VMware Tools starten¶

  • Klik op "Install Tools" in de gele balk onder het venster van de virtuele machine. Je kan ook in het menu "VM" de optie "Install VMware Tools" kiezen.
  • Open File Explorer in de virtuele machine en ga naar This PC.
  • Dubbelklik op de VMware Tools-dvd (DVD-station (D:) VMware Tools).
  • Bevestig de melding van gebruikersaccountbeheer met Ja (Yes).
  • De installer start automatisch.

5.2. Wizard van VMware Tools¶

Laat in de installatiewizard alle standaardinstellingen staan. Klik op Next, wacht tot de installatie klaar is en klik op Finish. Klik bij de melding om te herstarten op Yes.

6. Een snapshot nemen¶

Een snapshot is een momentopname van je virtuele machine. Gaat er later iets mis, dan kan je naar deze toestand terugkeren zonder opnieuw te installeren.

Meld je na de herstart opnieuw aan. Zodra je het Windows-bureaublad ziet, neem je een snapshot:

  • Klik in het VMware-menu op "VM".
  • Kies "Snapshot" en dan "Take Snapshot".
  • Geef de snapshot een duidelijke naam, zoals "Windows 11 Clean Install".
  • Klik op Take Snapshot en wacht tot de voortgangsbalk klaar is.
