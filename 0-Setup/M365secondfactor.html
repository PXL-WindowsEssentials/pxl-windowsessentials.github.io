    Microsoft 365 demo-tenant - Een tweede verificatiemethode instellen

    Toen je je voor het eerst aanmeldde bij de Microsoft 365 demo-tenant, moest je Multi-Factor Authentication (MFA) instellen met een Authenticator-app.

    In deze handleiding stellen we naast de Authenticator-app een tweede MFA-methode in. Zo heb je een alternatieve manier om je aan te melden als er iets misgaat met je primaire verificatiemethode of als je geen toegang meer hebt tot je Authenticator-app.

    Als tweede verificatiemethode gebruiken we je PXL-e-mailadres.

    1. Zorg dat je aangemeld bent op admin.microsoft.com met het account van je demo-tenant. Je kan de accountgegevens van je demo-tenant op elk moment opvragen via deze link: Dashboard - Microsoft 365 Dev Center.

    2. Klik rechtsboven op je initialen en kies "View Account".

    3. Klik in het linkermenu op "My Account" en selecteer vervolgens "Security Info".

    4. Klik op "Add a sign-in method" en kies "Email".

    5. Geef je PXL-e-mailadres in (formaat: voornaam.achternaam@student.pxl.be).

    6. Er wordt een verificatiecode naar je PXL-e-mailadres gestuurd. Open de e-mail, kopieer de code en plak ze in het verificatieveld.

    Je PXL-e-mailadres is nu ingesteld als extra aanmeldmethode. Als je ooit geen toegang meer hebt tot je Authenticator-app, kan je je nog altijd aanmelden met een tijdelijke verificatiecode die naar je PXL-e-mailadres wordt gestuurd.
