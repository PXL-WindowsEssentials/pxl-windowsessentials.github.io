Microsoft Visual Studio Pro (variant met persoonlijk Outlook-account)¶

Om aan alle lessen, labo's en evaluaties deel te nemen, heb je een Visual Studio Pro-licentie nodig. Die licentie is verplicht voor dit vak en koop je individueel aan via Academic Software. Gebruik deze variant als je Microsoft 365-tenant aan een persoonlijk Outlook-/Hotmail-account moet worden gekoppeld.

1. De licentie aankopen via Academic Software¶

1.1. Website¶

  1. Ga naar academicsoftware.eu/login
  2. Geef je PXL-e-mailadres in (formaat xxxxxx@student.pxl.be).
  3. Meld je daarna aan met je PXL-account.

1.2. Academic Software-portaal¶

  • Je bent nu op het Academic Software-portaal. Klik op de startpagina op "Alle tonen".

1.3. Winkelmandje voor Visual Studio Pro¶

  • Klik op "Toevoegen aan winkelmandje" bij het product "Visual Studio Subscriptions".

Doorloop de overige stappen om de aankoop af te ronden.

2. Licentie voor Visual Studio Pro aanvragen¶

2.1. Academic Software¶

  1. Ga naar https://www.academicsoftware.eu/
  2. Meld je indien nodig opnieuw aan met je PXL-account.

2.2. Software¶

  1. Klik na het aanmelden bovenaan op “Software”.
  2. Scroll naar beneden tot je de tegel “Visual Studio Pro” vindt en klik erop.

2.3. Licentie aanvragen¶

  • Klik op de volgende pagina onderaan op de knop “Licentie verkrijgen”.

3. Persoonlijk Outlook-/Hotmail-e-mailadres¶

Om de Microsoft 365-tenant aan te vragen via je Visual Studio Professional-licentie, moet je een persoonlijk Outlook-/Hotmail-e-mailadres doorgeven aan Academic Software. Je PXL-account kan hiervoor niet gebruikt worden.

  • Heb je al een persoonlijk Outlook-/Hotmail-account? Ga dan verder naar stap 4.
  • Heb je nog geen persoonlijk Outlook-/Hotmail-account? Maak er dan eerst een aan met deze handleiding: Handleiding: Een persoonlijk Outlook-/Hotmail-e-mailadres aanmaken.

4. Persoonlijk Outlook-/Hotmail-e-mailadres doorgeven¶

Zo kan Academic Software je Visual Studio Professional-licentie aan de juiste Microsoft 365-tenant koppelen.

Stuur een e-mail vanaf je PXL-e-mailadres naar support@academicsoftware.com. Gebruik onderstaand voorbeeld en vul je persoonlijke Outlook-/Hotmail-e-mailadres en je naam in.
