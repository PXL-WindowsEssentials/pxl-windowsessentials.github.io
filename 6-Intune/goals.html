    Doelstellingen Intune

    Intune: Enroll

    De student kan:

    • Een virtuele machine Windows 11 inschrijven in Intune tijdens de Windows OOBE met behulp van Autopilot.

    Intune: Configure

    De student kan:

    • configuratieprofielen toevoegen en toewijzen aan toestellen.
    • via Intune Microsoft Store-apps, MSI- en EXE-bestanden installeren op een Windows 11-virtuele machine.
    • Microsoft Store-apps, MSI- en EXE-bestanden beschikbaar stellen in de Company Portal.
    • raadplegen op welke toestellen een configuratieprofiel is toegepast.
    • raadplegen op welke toestellen een applicatie is geïnstalleerd.
    • een apparaat in Intune synchroniseren om de meest recente beleidsregels en acties op te halen.
    • een apparaat handmatig synchroniseren vanuit de Windows 11-virtuele machine, via de Windows Settings of door de Microsoft Intune Management Extension te herstarten.
    • De MDM instellingen aanpassen om te bepalen welke gebruikers toestellen mogen inschrijven.
    • Een deployment profile (implementatieprofiel) toepassen om de Windows OOBE te automatiseren

    Intune: Protect

    De student kan:

    • Een bepaalde Entra gebruiker als lokale administrator configureren voor een groep van virtuele machines
    • Windows LAPS configureren
    • Een nieuwe tijdelijk lokaal administrator wachtwoord genereren en opvragen in Intune.
    • zich aanmelden met een lokale administrator op een Windows 11 virtuele machine.

    Intune: Retire

    • Apparaten verwijderen door te wissen, buiten gebruik te stellen of handmatig uit te schrijven
