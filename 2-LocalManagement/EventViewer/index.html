Event Viewer¶

Windows registreert veel activiteit in logboeken. Je bekijkt ze met de Event Viewer.

Waarvoor gebruik je de Event Viewer?¶

  • Problemen oplossen: zoeken naar fouten en waarschuwingen rond een programma, service of stuurprogramma dat niet werkt.
  • Aanmeldingen nagaan: achterhalen wie zich wanneer (mislukt of succesvol) heeft aangemeld.
  • Beveiligingsincidenten onderzoeken: nagaan wat er op een toestel is gebeurd.
  • Updates en installaties controleren: bekijken of een update of installatie gelukt is.

Event Viewer openen¶

  1. Typ in Windows Search Event Viewer en druk op Enter.
  2. Of druk op Win + R, typ eventvwr.msc en druk op Enter.

De logboeken in de Event Viewer¶

De Event Viewer is opgedeeld in twee hoofdcategorieën:

  1. Windows Logs: bevatten algemene logboeken over het Windows-systeem. Ze zijn opgedeeld in vijf subcategorieën:

    • Application
    • Security
    • Setup
    • System
    • Forwarded Events

  2. Applications and Services Logs: bevatten gedetailleerde registraties van specifieke Windows-componenten en systeemfuncties.

Event ID¶

Een logboek bevat duizenden gebeurtenissen. Om snel te vinden wat je zoekt, moet je weten in welk logboek je moet zoeken en welk Event ID bij de gebeurtenis hoort. Elk type gebeurtenis heeft een vast ID. Hier zijn enkele voorbeelden:

ID Gebeurtenis Logboekcategorie
4624 Succesvolle aanmelding van een gebruiker Security
4647 Afmelding van een gebruiker Security
4625 Mislukte aanmeldpoging Security
12 Opstarten van het systeem System
6006 Afsluiten van het systeem System
41 Onjuist afsluiten van het systeem System
104 Systeemlogboeken gewist System
1102 Beveiligingslogboeken gewist Security
10000 Netwerkverbinding tot stand gebracht Applications and Services Logs > Microsoft > Windows > NetworkProfile
44 Windows-update gedownload Applications and Services Logs > Microsoft > Windows > WindowsUpdateClient

Voorbeeld: mislukte aanmeldpoging¶

Zo filter je op mislukte aanmeldpogingen, bijvoorbeeld om te controleren of iemand je wachtwoord probeert te raden:

  1. Open de Event Viewer en ga naar Windows Logs.
  2. Selecteer het logboek Security.
  3. Klik in het menu rechts op Filter Current Log.
  4. Geef Event ID 4625 in het filterveld in en klik op OK.
  5. Kies een gebeurtenis uit de gefilterde resultaten om de details te bekijken.
