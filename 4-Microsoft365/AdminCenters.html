    Microsoft 365 Admin Center

    De belangrijkste toegang tot je Microsoft 365-abonnement is het M365 Admin Center (admin.microsoft.com). In dit admin center kan je alle items configureren die over alle diensten van je abonnement heen gebruikt worden:

    • Users: maak gebruikers in je organisatie aan en beheer ze, zoals medewerkers of studenten. Je kan ook hun machtigingsniveau instellen of hun wachtwoord resetten.
    • Teams & groups: maak groepen in je organisatie aan en beheer ze, zoals een Microsoft 365-groep, Microsoft 365 Teams, distributiegroep, beveiligingsgroep of gedeelde mailbox.
    • Roles: wijs ingebouwde Microsoft Entra-rollen (Microsoft Entra ID) toe aan gebruikers die toegang nodig hebben tot andere admin centers en resources in Microsoft Entra ID, zoals gebruikers, groepen en apps die de Microsoft Graph API gebruiken.
    • Resources: maak resources aan en beheer ze, zoals een SharePoint-sitecollectie.
    • Billing: bekijk, koop of annuleer abonnementen voor je organisatie. Bekijk vorige factureringsoverzichten of het aantal toegewezen licenties per gebruiker.
    • Support: bekijk bestaande serviceaanvragen of maak nieuwe aan.
    • Settings: beheer globale instellingen voor apps zoals e-mail, sites en Microsoft 365. Wijzig je wachtwoordbeleid en vervaldatum. Voeg domeinnamen zoals contoso.com toe en werk ze bij. Wijzig het profiel van je organisatie en de releasevoorkeuren. En kies of partners toegang hebben tot je admin center.
    • Setup: beheer bestaande domeinen, schakel multi-factor authentication in en beheer het, beheer de beheerderstoegang, migreer gebruikersmailboxen naar Microsoft 365, beheer feature-updates en help gebruikers bij het installeren van hun apps in Microsoft 365.
    • Reports: zie in één oogopslag hoe je organisatie Microsoft 365 gebruikt, met gedetailleerde rapporten over e-mailgebruik, Microsoft 365-activaties en meer.
    • Health: bekijk de status (health) in één oogopslag. Je kan ook meer details en de statusgeschiedenis bekijken.

    Door SSO (Single Sign-On) moet je het Microsoft Admin Center altijd openen in een privévenster van je browser of in een andere browser dan die je voor je PXL-e-mailadres gebruikt. Zo kan je aanmelden met het juiste adminaccount en niet met je schoolaccount via SSO.

    Admin centers per dienst

    Wanneer je een specifieke dienst wil configureren, moet je naar het juiste admin center voor die dienst gaan. Het specifieke admin center bundelt alle configuratie-items voor een bepaalde dienst. Zo worden we niet overweldigd door alle instellingen die voor alle diensten geconfigureerd kunnen worden. Hieronder een lijst van de specifieke admin centers die we tijdens de cursus gebruiken:

    Dienst Url
    Entra ID entra.microsoft.com
    Endpoint manager intune.microsoft.com
    Exchange exchange.microsoft.com
    SharePoint <tenantname>-admin.sharepoint.com
    Teams admin.teams.microsoft.com
    Security security.microsoft.com

    Je hoeft niet alle URL's van buiten te kennen. In het Microsoft 365 admin center is er een pagina met alle beschikbare admin centers voor je abonnement, met directe links ernaar.

    Toegangsbeveiliging

    Microsoft 365 gebruikt een RBAC-beveiligingssysteem. RBAC staat voor:

    • Role
    • Based
    • Access
    • Control

    Dit beveiligingsprincipe wordt algemeen gebruikt in alle online en on-premises oplossingen. Het belangrijkste doel van RBAC is om altijd een duidelijk overzicht te hebben van de toegangsrechten van elke gebruiker, en te vermijden dat een gebruiker dubbele toegang krijgt. Dat gebeurt met behulp van rollen. RBAC bepaalt dat toegangsrechten enkel aan een rol kunnen worden toegekend. Als een gebruiker deze toegang nodig heeft, moet de gebruiker de rol krijgen. Aan één rol kunnen meerdere toegangsrechten worden toegekend (dit is vaak het geval).

    Met Microsoft 365 kan je je eigen rollen aanmaken. Dat wordt echter niet als best practice beschouwd wanneer je net begint met M365, vanwege de grote hoeveelheid toegangsrechten die toegekend kunnen worden. Het is dan ook het best om de ingebouwde rollen van Microsoft te gebruiken tot je vertrouwd bent met alle toegangsrechten die toegekend kunnen worden.

    Rol Toegang
    Global administrator Heeft volledige beheerdersrechten op M365
    User admin Kan gebruikers beheren voor alle admin centers
    Group admin Kan groepen beheren voor alle admin centers
    <Admin center> admin Heeft volledige toegang tot het specifieke admin center
    License admin Kan licenties toekennen, intrekken, opnieuw verwerken, ...
    Billing admin Beheert alle factureringsfuncties
    Password admin Kan het wachtwoord van niet-beheerders wijzigen
    Service Support admin Kan supporttickets openen

    Algemeen advies voor rollen

    RBAC biedt geweldige mogelijkheden, maar kan ook misbruikt worden. Om misbruik van RBAC in Microsoft 365 te vermijden, moeten enkele algemene richtlijnen gevolgd worden:

    • Slechts enkele personen mogen de rol Global Administrator hebben. M365 waarschuwt je ook wanneer er te veel Global Administrators in je abonnement zijn.
    • Pas altijd het principe van Least Privilege toe: geef enkel toegang als de gebruiker die toegang nodig heeft voor zijn werk. Als hij die toegang niet nodig heeft om zijn job uit te oefenen, heeft hij die toegang in het algemeen niet nodig.
    • Gebruik altijd MFA voor alle rollen (dit wordt door Microsoft afgedwongen).
    • Probeer een rol altijd toe te kennen aan een gebruikersgroep in plaats van rechtstreeks aan een gebruiker. Zo hou je een beter overzicht.
    • Zorg er altijd voor dat je een "Break the glass"-adminaccount hebt. Dit is een specifieke gebruiker waarvan de aanmeldgegevens meestal in een kluis worden bewaard en die enkel gebruikt wordt wanneer alle andere beheerders buitengesloten zijn.
