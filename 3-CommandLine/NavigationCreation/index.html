Navigeren en bestandsbeheer¶

Navigeren en bestandsbeheer zijn basisfuncties van elk besturingssysteem. Het besturingssysteem gebruikt ze om correct te functioneren, nieuwe apps te installeren en systeembestanden te beheren. Gebruikers gebruiken ze om persoonlijke documenten op te slaan.

De meeste gebruikers doen bestandsbeheer in de GUI (File Explorer). Systeembeheerders gebruiken vaak PowerShell, omdat je daarmee veel bestanden tegelijk kan beheren en taken kan automatiseren. In dit hoofdstuk bekijk je de meest voorkomende cmdlets voor bestandsbeheer en hoe je ze correct gebruikt.

Navigeren in de CLI¶

Van directory veranderen¶

Een van de meest uitgevoerde acties in de CLI is naar een andere directory gaan. Daarvoor gebruik je de cmdlet Set-Location (alias cd). De prompt toont steeds de directory waarin je je bevindt.

Bijvoorbeeld:

PS C:\Windows> Set-Location System32
PS C:\Windows\System32>

Absoluut vs relatief pad¶

Je kan op twee manieren naar een directory verwijzen:

  • Absoluut: je geeft het volledige pad op, beginnend bij de volumeletter. Het resultaat is altijd hetzelfde, ongeacht waar je je bevindt.\ Voorbeeld: je bevindt je in C:\WinEss en wil naar de map Office16 van Microsoft Office. Dat kan met Set-Location 'C:\Program Files\Microsoft Office\Office16\' of met de alias: cd 'C:\Program Files\Microsoft Office\Office16\'. Staan er spaties in het pad, zet het dan tussen aanhalingstekens.

  • Relatief: het pad vertrekt vanuit de directory waarin je je op dat moment bevindt. Je gebruikt hiervoor:

    • . voor de huidige directory
    • .. voor de bovenliggende directory
    • \ (of /) als scheidingsteken tussen de mappen in het pad

    Stel dat we de volgende mappenstructuur hebben:

    PS C:\PXL> tree
Folder PATH listing for volume Windows
Volume serial number is B2D6-03D9
C:.
├───Bach
│   ├───1ste
│   ├───2de
│   └───3de
└───Grad
    ├───1ste
    ├───2de
    └───3de

    Je bevindt je in C:\PXL\Bach\3de en wil naar C:\PXL\Grad\1ste. Je gaat twee niveaus omhoog (..\..) en dan naar beneden via Grad\1ste: ..\..\Grad\1ste

    PS C:\PXL\Bach\3de> Set-Location ..\..\Grad\1ste\
PS C:\PXL\Grad\1ste>

    Begint het pad niet met een volumeletter of met . of .., dan is het ook een relatief pad. PowerShell zoekt dan een map in de huidige directory.

    PS C:\PXL\Grad> Set-Location 2de
PS C:\PXL\Grad\2de>

Inhoud van een directory¶

In File Explorer zie je de inhoud van een map zodra je erop klikt. In de CLI moet je daarvoor een cmdlet uitvoeren: Get-ChildItem (alias dir of ls).

Bijvoorbeeld:

PS C:\PXL> Get-ChildItem


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:35                Bach
d-----        13/08/2025     11:36                Grad

Standaard toont deze cmdlet de inhoud van de huidige directory. Met een absoluut of relatief pad bekijk je de inhoud van eender welke directory.

Bijvoorbeeld:

PS C:\PXL> Get-ChildItem C:\PXL\Bach\


    Directory: C:\PXL\Bach


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:35                1ste
d-----        13/08/2025     11:35                2de
d-----        13/08/2025     11:35                3de
-a----        13/08/2025     11:57              6 studenten.txt
-a----        13/08/2025     11:57              6 vakken.txt


PS C:\PXL> Get-ChildItem .\Bach\


    Directory: C:\PXL\Bach


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:35                1ste
d-----        13/08/2025     11:35                2de
d-----        13/08/2025     11:35                3de
-a----        13/08/2025     11:57              6 studenten.txt
-a----        13/08/2025     11:57              6 vakken.txt

In de kolom Mode zie je het type item: d staat voor directory en a voor een bestand. Wil je enkel de bestanden of enkel de directories zien, gebruik dan een parameter:

  • -File toont enkel de bestanden.
  • -Directory toont enkel de directories.
PS C:\PXL> Get-ChildItem -File .\Bach\


    Directory: C:\PXL\Bach


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        13/08/2025     11:57              6 studenten.txt
-a----        13/08/2025     11:57              6 vakken.txt


PS C:\PXL> Get-ChildItem -Directory .\Bach\


    Directory: C:\PXL\Bach


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:35                1ste
d-----        13/08/2025     11:35                2de
d-----        13/08/2025     11:35                3de

Environment-variabelen¶

Veel waarden in Windows hangen af van de context, zoals de aangemelde gebruiker, de computer of de sessie. Environment-variabelen geven die waarden een vaste naam, bijvoorbeeld USERPROFILE of TEMP. In PowerShell verwijs je ernaar met $env:NAAM. Zo werken je commando's op elke computer en voor elke gebruiker, zonder dat je vaste paden moet typen. Enkele veelvoorkomende variabelen:

Variabele Info
APPDATA Bevat het absolute pad van de map AppData in het gebruikersprofiel
HOMEDRIVE Bevat het volume waarop de profielen worden opgeslagen
HOMEPATH Bevat het absolute pad van de huidige gebruiker
OneDrive Bevat het absolute pad van de OneDrive-map (indien geconfigureerd)
ProgramFiles Bevat het absolute pad van de map Program Files
SystemDrive Bevat de volumeletter waarop het Windows-systeem is geïnstalleerd
Systemroot Bevat het absolute pad van de map Windows
Username Bevat de gebruikersnaam van de huidige gebruiker
USERDOMAIN Bevat de domeinnaam waaraan de computer is toegevoegd

Voorbeeld:

PS C:\PXL\Bach> cd $Env:HOMEPATH
PS C:\Users\20004607>cd $Env:SystemRoot
PS C:\WINDOWS> cd $Env:APPDATA
PS C:\Users\20004607\AppData\Roaming>

Bestandsbeheer¶

Een directory aanmaken¶

Je maakt een directory aan met New-Item -ItemType Directory <dirname>.

PS C:\PXL> New-Item -ItemType Directory Old


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     14:07                Old

Je kan ook het oude MS-DOS-commando md (of mkdir) gebruiken. Dat is korter, maar de cmdlet is duidelijker.

Een bestand aanmaken¶

Je maakt een leeg bestand aan met New-Item -ItemType File <filename>.

PS C:\PXL> New-Item -ItemType File Old.txt


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        13/08/2025     14:08              0 Old.txt

Naam wijzigen¶

De naam van een bestand of map wijzig je met de cmdlet Rename-Item.

PS C:\PXL> Get-ChildItem -Directory


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:57                Bach
d-----        13/08/2025     11:36                Grad
d-----        13/08/2025     14:07                Old


PS C:\PXL> Rename-Item Old New
PS C:\PXL> Get-ChildItem -Directory


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:57                Bach
d-----        13/08/2025     11:36                Grad
d-----        13/08/2025     14:07                New

Met dezelfde cmdlet hernoem je een bestand.

PS C:\PXL> Get-ChildItem -File


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        13/08/2025     14:08              0 Old.txt


PS C:\PXL> Rename-Item .\Old.txt New.txt
PS C:\PXL> Get-ChildItem -File


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        13/08/2025     14:08              0 New.txt

Een bestand/directory verwijderen¶

Een directory of bestand verwijder je met de cmdlet Remove-Item.

PS C:\PXL> Get-ChildItem -File


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        13/08/2025     14:08              0 New.txt


PS C:\PXL> Remove-Item .\New.txt
PS C:\PXL> Get-ChildItem -File
PS C:\PXL>

Of een directory verwijderen.

PS C:\PXL> Get-ChildItem -Directory


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:57                Bach
d-----        13/08/2025     11:36                Grad
d-----        13/08/2025     14:07                New


PS C:\PXL> Remove-Item .\New\
PS C:\PXL> Get-ChildItem -Directory


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:57                Bach
d-----        13/08/2025     11:36                Grad

⚠️ Remove-Item verplaatst niets naar de Prullenbak: verwijderde items zijn definitief weg.

Is de directory die je wil verwijderen niet leeg, voeg dan -Recurse -Force toe. Anders vraagt PowerShell voor elk onderliggend item om bevestiging.

  • -Recurse verwijdert ook alle bestanden en directories in de directory.
  • -Force vraagt geen bevestiging.

Bestand(en)/directory kopiëren¶

Met Copy-Item kopieer je bestanden of directories naar een andere locatie. Afhankelijk van wat je wil, gebruik je parameters of wildcards. In de voorbeelden hieronder staat de gebruiker in een submap van Bach:

  • Copy-Item Bach.txt ..\Bach\: kopieert het bestand Bach.txt naar de directory Bach
  • Copy-Item * ..\Bach: kopieert alle bestanden en directories naar de directory Bach
  • Copy-Item -Recurse -Force 1ste\ ..\Bach\: kopieert de volledige directory met alle subdirectories en bestanden naar de directory Bach

Bestand(en)/directory verplaatsen¶

Met Move-Item verplaats je bestanden of directories naar een andere locatie. Het item staat daarna niet meer op de oorspronkelijke plaats.

  • Move-Item Bach.txt ..\Bach\: verplaatst het bestand Bach.txt naar de directory Bach
  • Move-Item * ..\Bach: verplaatst alle bestanden en directories naar de directory Bach
  • Move-Item 1ste\ ..\Bach\: verplaatst de volledige directory met alle subdirectories en bestanden naar de directory Bach
