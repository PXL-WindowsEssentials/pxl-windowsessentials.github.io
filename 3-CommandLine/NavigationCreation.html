    Navigeren en bestandsbeheer

    Navigatie en bestandsbeheer zijn twee basisfuncties van alle besturingssystemen. Ze laten het besturingssysteem toe om:

    • correct te functioneren,
    • nieuwe apps te installeren,
    • systeembestanden aan te maken en te beheren,
    • ...

    Daarnaast kan de eindgebruiker de schijven gebruiken om persoonlijke documenten op te slaan.

    In Windows gebruiken de meeste gebruikers de GUI voor alle taken rond bestandsbeheer. Ervaren systeembeheerders grijpen voor bestandsbeheer in Windows echter vaak naar PowerShell. In dit hoofdstuk bekijken we de meest voorkomende cmdlets voor bestandsbeheer en hoe je ze correct gebruikt.

    Navigeren in de CLI

    Van directory veranderen

    Een van de meest uitgevoerde acties in de CLI is naar een andere directory gaan. Daarvoor gebruiken we de cmdlet Set-Location.

    Bijvoorbeeld:

    PS C:\Windows> Set-Location System32
PS C:\Windows\System32>

    Absoluut vs relatief pad

    Wanneer we van de ene directory naar de andere gaan, kunnen we twee methodes gebruiken om naar de juiste directory te verwijzen:

    • Absoluut: bij deze methode geef je het volledige pad van de directory op, beginnend vanaf het begin van het huidige volume.
      Bijvoorbeeld: we bevinden ons in C:\WinEss en willen naar de map Office16 van Microsoft Office gaan. Dat kan met de cmdlet Set-Location 'C:\Program Files\Microsoft Office\Office16\' of met de alias cd: cd 'C:\Program Files\Microsoft Office\Office16\'.

    • Relatief: bij deze methode gebruiken we ., .. of / om het pad naar de directory op te geven, maar nu wordt het pad opgebouwd vanuit de directory waarin we ons op dat moment bevinden.

      • . verwijst naar de huidige directory
      • .. verwijst naar de bovenliggende directory in de mappenboom
      • / of \ verwijst naar het begin van de volgende directory in de boom

      Stel dat we de volgende mappenstructuur hebben:

      PS C:\PXL> tree
Folder PATH listing for volume Windows
Volume serial number is B2D6-03D9
C:.
├───Bach
│   ├───1ste
│   ├───2de
│   └───3de
└───Grad
    ├───1ste
    ├───2de
    └───3de

      We bevinden ons in de directory C:\PXL\Bach\3de en willen naar de directory C:\PXL\Grad\1ste. Dan kunnen we het volgende relatieve pad gebruiken: ../../Grad/1ste

      PS C:\PXL\Bach\3de> Set-Location ..\..\Grad\1ste\
PS C:\PXL\Grad\1ste>

      Geef je geen enkel van de relatieve symbolen op, dan interpreteert PowerShell dit ook als een relatief pad en veronderstelt het dat je naar een object dieper in de boom wil verwijzen, vertrekkend vanuit de huidige directory.

      PS C:\PXL\Grad> Set-Location 2de
PS C:\PXL\Grad\2de>

    Inhoud van een directory

    Een van de voordelen van File Explorer voor bestandsbeheer is dat we onmiddellijk de inhoud van een directory zien wanneer we erop klikken. Via de CLI moeten we echter een specifieke cmdlet uitvoeren om de inhoud van de huidige directory te zien. Daarvoor kunnen we de cmdlet Get-ChildItem gebruiken.

    Bijvoorbeeld:

    PS C:\PXL> Get-ChildItem


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:35                Bach
d-----        13/08/2025     11:36                Grad

    Standaard toont deze cmdlet de volledige inhoud van de huidige directory. Door de hierboven beschreven padmethodes te gebruiken, kunnen we echter ook de inhoud van eender welke directory bekijken.

    Bijvoorbeeld:

    PS C:\PXL> Get-ChildItem C:\PXL\Bach\


    Directory: C:\PXL\Bach


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:35                1ste
d-----        13/08/2025     11:35                2de
d-----        13/08/2025     11:35                3de
-a----        13/08/2025     11:57              6 studenten.txt
-a----        13/08/2025     11:57              6 vakken.txt


PS C:\PXL> Get-ChildItem .\Bach\


    Directory: C:\PXL\Bach


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:35                1ste
d-----        13/08/2025     11:35                2de
d-----        13/08/2025     11:35                3de
-a----        13/08/2025     11:57              6 studenten.txt
-a----        13/08/2025     11:57              6 vakken.txt

    In de laatste uitvoer zien we de volledige inhoud van de directory. Als we enkel de bestanden of enkel de directories willen zien, kunnen we gebruikmaken van de beschikbare parameters van deze cmdlet:

    • -File toont enkel de bestanden
    • -Directory toont enkel de directories.
    PS C:\PXL> Get-ChildItem -File .\Bach\


    Directory: C:\PXL\Bach


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        13/08/2025     11:57              6 studenten.txt
-a----        13/08/2025     11:57              6 vakken.txt


PS C:\PXL> Get-ChildItem -Directory .\Bach\


    Directory: C:\PXL\Bach


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:35                1ste
d-----        13/08/2025     11:35                2de
d-----        13/08/2025     11:35                3de

    Environment-variabelen

    Veel waarden in Windows hangen af van de context waarin een proces draait, zoals de aangemelde gebruiker, de computer of de sessie. Environment-variabelen geven deze waarden een vaste naam, bijvoorbeeld USERPROFILE of TEMP. In PowerShell verwijs je ernaar als $env:NAME. De volgende tabel geeft een overzicht van enkele van de meest voorkomende environment-variabelen.

    Variabele Info
    APPDATA Bevat het absolute pad van de map AppData in het gebruikersprofiel
    HOMEDRIVE Bevat het volume waarop de profielen worden opgeslagen
    HOMEPATH Bevat het absolute pad van de huidige gebruiker
    OneDrive Bevat het absolute pad van de OneDrive-map (indien geconfigureerd)
    ProgramFiles Bevat het absolute pad van de map Program Files
    SystemDrive Bevat de volumeletter waarop het Windows-systeem is geïnstalleerd
    Systemroot Bevat het absolute pad van de map Windows
    Username Bevat de gebruikersnaam van de huidige gebruiker
    USERDOMAIN Bevat de domeinnaam waaraan de computer is toegevoegd

    Voorbeeld:

    PS C:\PXL\Bach> cd $Env:HOMEPATH
PS C:\Users\20004607>cd $Env:SystemRoot
PS C:\WINDOWS> cd $Env:APPDATA
PS C:\Users\20004607\AppData\Roaming>

    Bestandsbeheer

    Een directory aanmaken

    Een directory aanmaken is een eenvoudige taak die je kan uitvoeren met de cmdlet New-Item -ItemType Directory <dirname>

    PS C:\PXL> New-Item -ItemType Directory Old


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     14:07                Old

    Om een directory aan te maken kan je ook nog altijd het oude MS-DOS-commando md gebruiken. Dit is geen alias, maar het echte oude MS-DOS-commando dat nog altijd in PowerShell is opgenomen.

    Een bestand aanmaken

    Een leeg bestand aanmaken is een eenvoudige taak die je kan uitvoeren met de cmdlet New-Item -ItemType File <filename>

    PS C:\PXL> New-Item -ItemType File Old.txt


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        13/08/2025     14:08              0 Old.txt

    Naam wijzigen

    De naam van een bestand of map wijzig je met de cmdlet Rename-Item.

    PS C:\PXL> Get-ChildItem -Directory


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:57                Bach
d-----        13/08/2025     11:36                Grad
d-----        13/08/2025     14:07                Old


PS C:\PXL> Rename-Item Old New
PS C:\PXL> Get-ChildItem -Directory


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:57                Bach
d-----        13/08/2025     11:36                Grad
d-----        13/08/2025     14:07                New

    Dezelfde cmdlet kan je gebruiken om de naam van een bestand te wijzigen.

    PS C:\PXL> Get-ChildItem -File


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        13/08/2025     14:08              0 Old.txt


PS C:\PXL> Rename-Item .\Old.txt New.txt
PS C:\PXL> Get-ChildItem -File


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        13/08/2025     14:08              0 New.txt

    Een bestand/directory verwijderen

    Een directory of bestand verwijder je met de cmdlet Remove-Item.

    PS C:\PXL> Get-ChildItem -File


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        13/08/2025     14:08              0 New.txt


PS C:\PXL> Remove-Item .\New.txt
PS C:\PXL> Get-ChildItem -File
PS C:\PXL>

    Of een directory verwijderen.

    PS C:\PXL> Get-ChildItem -Directory


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:57                Bach
d-----        13/08/2025     11:36                Grad
d-----        13/08/2025     14:07                New


PS C:\PXL> Remove-Item .\New\
PS C:\PXL> Get-ChildItem -Directory


    Directory: C:\PXL


Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        13/08/2025     11:57                Bach
d-----        13/08/2025     11:36                Grad

    Als de directory die je wil verwijderen niet leeg is, moet je de volgende parameters toevoegen: -Recurse -Force. Deze parameters voorkomen fouten bij het uitvoeren van de cmdlet.

    • -Recurse geeft de cmdlet aan dat alle bestanden en directories in de directory die je verwijdert, ook verwijderd moeten worden
    • -Force geeft de cmdlet aan dat ze geen toestemming moet vragen om de bestanden en directories in de te verwijderen directory te verwijderen.

    Bestand(en)/directory kopiëren

    Als we een bestand, bestanden, directory of directories naar een andere locatie willen kopiëren, kunnen we de cmdlet Copy-Item gebruiken. Om de specifieke taak uit te voeren, moeten we parameters toevoegen of wildcards gebruiken:

    • Copy-Item Bach.txt ..\Bach\: kopieert het bestand Bach.txt naar de directory Bach met een relatief pad
    • Copy-Item * ..\Bach: kopieert alle bestanden en directories naar de directory Bach met een relatief pad
    • Copy-Item -Recurse -Force 1ste\ ..\Bach\: kopieert de volledige directory en alle subdirectories/bestanden naar de directory Bach met een relatief pad

    Bestand(en)/directory verplaatsen

    Als we een bestand, bestanden, directory of directories naar een andere locatie willen verplaatsen, kunnen we de cmdlet Move-Item gebruiken. Om de specifieke taak uit te voeren, moeten we parameters toevoegen of wildcards gebruiken:

    • Move-Item Bach.txt ..\Bach\: verplaatst het bestand Bach.txt naar de directory Bach met een relatief pad
    • Move-Item * ..\Bach: verplaatst alle bestanden en directories naar de directory Bach met een relatief pad
    • Move-Item -Recurse -Force 1ste\ ..\Bach\: verplaatst de volledige directory en alle subdirectories/bestanden naar de directory Bach met een relatief pad
