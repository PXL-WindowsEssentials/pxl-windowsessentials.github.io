    Doelstellingen Command Line

    Algemeen

    De student kan:

    • PowerShell shell opstarten in terminal:
      • Als administrator
      • Als gewone gebruiker
    • De basisstructuur van een powershell cmdlet uitleggen
    • Het juiste PowerShell cmdlet opzoeken aan de hand het get-command
    • Helppagina van een cmdlet opzoeken en hierin volgende informatie op vragen:
      • Parameters
      • Voorbeelden
    • het verschil uitleggen tussen Terminal, PowerShell cmdlets, cmd-commands en native commands.

    PowerShell gebruik

    De student kan PowerShell gebruiken:

    • Om zich in het systeem te navigeren door gebruik te maken van absolute en relatieve paden
    • Om de inhoud van een directory weer te geven
    • Om een directory of file aan te maken of verwijderen
    • Om een directory(s) of file(s) te kopiëren of verplaatsen
    • Om een directory of file van naam te wijzigen
    • Environment-variabelen gebruiken in navigatie en creatie cmdlets.

    PowerShell algemene doeleinden

    De student kan PowerShell gebruiken voor algemene doeleinden:

    • De inhoud van een file te bekijken
    • Het systeem te laten herstarten
    • De geschiedenis van de reeds ingevoerde cmdlets te raadplegen
    • De CLI op te schonen

    PowerShell diagnostische doeleinden

    De student kan PowerShell gebruiken voor systeem diagnostische doeleinden:

    • Processen raadplegen, starten en stoppen
    • Services raadplegen, starten en stoppen
    • Event log raadplegen
    • Hardware-informatie raadplegen: disks, netwerk adapters, volumes, partities, printers,
    • Gehele computer informatie weergeven

    PowerShell netwerk

    De student kan PowerShell gebruiken voor netwerk gerelateerde doeleinden:

    • IP informatie opvragen van één of alle netwerkadapters: IP, Subnet, DNS server, Default Gateway
    • Overzicht geven van alle UDP en TCP connecties.
    • Nagaan of een host bereikbaar is.
    • DNS-lookups uitvoeren
    • Nagaan of routering naar bepaalde host correct is

    PowerShell scripts

    De student kan:

    • de Execution Policy raadplegen.
    • de Execution Policy aanpassen.
    • scripts uitvoeren.
