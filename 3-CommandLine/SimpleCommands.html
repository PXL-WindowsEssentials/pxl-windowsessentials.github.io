    Veelgebruikte cmdlets

    In dit hoofdstuk geven we een overzicht van enkele veelgebruikte commando's. We introduceren cmdlets in de volgende categorieën:

    • Algemene cmdlets
    • Cmdlets voor systeemdiagnose
    • Netwerkgerelateerde cmdlets

    Alle onderstaande cmdlets hebben één of meer parameters met hun eigen functionaliteit. Gebruik de cmdlet Get-Help om te leren wat ze kunnen.

    Algemene cmdlets

    • Get-History

      Telkens wanneer we een cmdlet ingeven, wordt die bewaard in een txt-bestand in het gebruikersprofiel ($Env:AppData\Microsoft\Windows\PowerShell\PSReadLine). Je kan in het bestand zoeken, of je kan de geschiedenis van de cmdlets bekijken met de cmdlet Get-History.

    • Get-Content

      Als je de inhoud van een bestand in PowerShell wil zien, kan je de cmdlet Get-Content gebruiken.

      Bijvoorbeeld:

      PS C:\PXL\Bach> Get-Content .\studenten.txt

Lyra Thalwyn
Dren Solakar
Maelis Virel
Torven Kray
Isara Delune
Kaelen Mirthas
Nyra Quellis
Jorak Fenmoor
Selene Araveth
PS C:\PXL\Bach>

    • Clear-Host

      Als het PowerShell-terminalvenster vol raakt, kan je het scherm van de shell leegmaken met Clear-Host.

    • Restart-Computer

      Via PowerShell kan je de computer ook herstarten met Restart-Computer.

    Cmdlets voor systeemdiagnose

    • Get|Stop-Process

      Alle processen die op je systeem draaien, kunnen via PowerShell beheerd worden. Afhankelijk van de actie die je op de processen wil uitvoeren, moet je een ander verb in de cmdlet gebruiken:

      • Get-Process: geeft een overzicht van de huidige actieve processen op je systeem.
      • Stop-Process: stopt een bepaald proces op je systeem. Stop-Process -Name msedge stopt alle Edge-processen die momenteel op het systeem draaien.

    • Get|Start|Stop-Service

      Alle services die op je systeem geconfigureerd zijn, kunnen beheerd worden met <Verb>-Service. Met het juiste verb en de juiste parameters kan je de services controleren (als administrator):

      • Get-Service: geeft een overzicht van alle momenteel geconfigureerde services op je systeem.
      • Start-Service: start een specifieke service via de parameter -Name. Start-Service -Name XboxNetApiSvc start de Xbox Networking-service op je systeem.
      • Stop-Service: stopt een specifieke service. Stop-Service -Name XboxNetApiSvc stopt de Xbox Networking-service.

    • Get-EventLog

      Met deze cmdlet kan je zoeken in de Windows-eventlogbestanden. Get-EventLog -LogName System geeft alle System-logs. Met extra parameters kan je de logs verder verfijnen.

    • Get-Disk

      Deze cmdlet geeft je een overzicht van alle geïnstalleerde ssd's.

## Netwerkgerelateerde cmdlets

De commando's die in deze paragraaf worden uitgelegd, worden vaak gebruikt door systeem- en netwerkengineers. De meest gebruikte commando's zijn echter geen PowerShell-cmdlets. Het zijn ingebouwde Windows-toepassingen (te vinden in `C:\Windows\System32`) die afstammen van MS-DOS-batch en nog steeds beschikbaar zijn in PowerShell of Command Prompt. Omdat deze commando's (eigenlijk toepassingen) nog vaak gebruikt worden, leggen we het gebruik ervan uit en geven we ook het juiste PowerShell-alternatief. Beide kunnen gebruikt worden.

- **netstat**

Dit commando geeft een overzicht van alle huidige netwerkverbindingen voor UDP en TCP.
- `-a`: toont alle verbindingen en luisterpoorten.
- `-n`: lost de IP-adressen niet op en toont het ruwe poortnummer.
- `-p PROTO`: toont enkel verbindingen voor het opgegeven protocol. `netstat -n -p TCP` toont de huidige TCP-verbindingen.

    PS C:\PXL\Bach> netstat -n -p TCP

- **ping**

Dit commando test of een bepaald IP-adres bereikbaar is. Standaard stuurt dit commando 4 ICMP-echo's naar het opgegeven IP-adres en toont het resultaat en de statistieken.

    PS C:\PXL\Bach> ping 8.8.8.8

    Pinging 8.8.8.8 with 32 bytes of data: Reply from 8.8.8.8: bytes=32 time=19ms TTL=117 Reply from 8.8.8.8: bytes=32 time=17ms TTL=117 Reply from 8.8.8.8: bytes=32 time=18ms TTL=117 Reply from 8.8.8.8: bytes=32 time=19ms TTL=117

    Ping statistics for 8.8.8.8: Packets: Sent = 4, Received = 4, Lost = 0 (0% loss), Approximate round trip times in milli-seconds: Minimum = 17ms, Maximum = 19ms, Average = 18ms

    - `-t`: voert een continue ping uit tot je het commando beëindigt

Als je de PowerShell-variant wil gebruiken, kan je de cmdlet `Test-Connection` gebruiken.

    PS C:\PXL\Bach> Test-Connection 8.8.8.8

    Source Destination IPV4Address IPV6Address Bytes Time(ms)

    5CD322B2D8 8.8.8.8 8.8.4.4 2001:4860:4860::8844 32 19 5CD322B2D8 8.8.8.8 8.8.4.4 2001:4860:4860::8844 32 18 5CD322B2D8 8.8.8.8 8.8.4.4 2001:4860:4860::8888 32 18 5CD322B2D8 8.8.8.8 8.8.8.8 2001:4860:4860::8888 32 19

    - **nslookup**

Met dit commando kan je een DNS-lookup uitvoeren (een naam omzetten naar een IP-adres):

    PS C:\PXL\Bach> nslookup pxl.be Server: hass02.dnsresv6.prd.telenet-ops.be Address: 2a02:1800:100::43:2

    Non-authoritative answer: Name: pxl.be Address: 193.190.154.242

    
Het PowerShell-equivalent van nslookup is `Resolve-DnsName`.

    PS C:\PXL\Bach> Resolve-DnsName pxl.be

    Name Type TTL Section IPAddress

    pxl.be A 3288 Answer 193.190.154.242

    
- **tracert**

Tracert is een afkorting van traceroute. Met dit commando kan je elke hop identificeren die een pakket doorloopt voordat het zijn bestemming bereikt. Als het pakket zijn bestemming niet bereikt, kan je met dit commando onderzoeken hoe het pakket gerouteerd wordt en waar het misgaat.

    PS C:\PXL\Bach> tracert -d 8.8.8.8

    Tracing route to 8.8.8.8 over a maximum of 30 hops

    1     4 ms    30 ms     4 ms  192.168.0.1
2    14 ms    14 ms    20 ms  84.193.80.1
3    18 ms    15 ms    24 ms  213.224.201.98
4     *        *        *     Request timed out.
5    37 ms    19 ms    20 ms  72.14.204.36
6    21 ms    18 ms    16 ms  142.251.253.185
7    22 ms    18 ms    19 ms  216.239.62.189
8    20 ms    20 ms    19 ms  8.8.8.8

    Trace complete.

    
Het PowerShell-equivalent van tracert is `Test-NetConnection -TraceRoute`

    PS C:\PXL\Bach> Test-NetConnection -TraceRoute 8.8.8.8

    ComputerName : 8.8.8.8 RemoteAddress : 8.8.8.8 InterfaceAlias : Wi-Fi SourceAddress : 192.168.0.215 PingSucceeded : True PingReplyDetails (RTT) : 20 ms TraceRoute : 192.168.0.1 84.193.80.1 213.224.201.98 213.224.250.175 72.14.204.36 142.251.253.185 216.239.62.189 8.8.8.8
