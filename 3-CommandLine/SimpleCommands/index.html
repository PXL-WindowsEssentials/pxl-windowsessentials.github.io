Veelgebruikte cmdlets¶

In dit hoofdstuk geven we een overzicht van enkele veelgebruikte commando's. We introduceren cmdlets in de volgende categorieën:

  • Algemene cmdlets
  • Cmdlets voor systeemdiagnose
  • Netwerkgerelateerde cmdlets

Alle onderstaande cmdlets hebben één of meer parameters met hun eigen functionaliteit. Gebruik de cmdlet Get-Help om te leren wat ze kunnen.

Algemene cmdlets¶

  • Get-History

    Telkens wanneer we een cmdlet ingeven, wordt die bewaard in een txt-bestand in het gebruikersprofiel ($Env:AppData\Microsoft\Windows\PowerShell\PSReadLine). Je kan in het bestand zoeken, of je kan de geschiedenis van de cmdlets bekijken met de cmdlet Get-History.

  • Get-Content

    Als je de inhoud van een bestand in PowerShell wil zien, kan je de cmdlet Get-Content gebruiken.

    Bijvoorbeeld:

    PS C:\PXL\Bach> Get-Content .\studenten.txt
Aelric Vornan
Lyra Thalwyn
Dren Solakar
Maelis Virel
Torven Kray
Isara Delune
Kaelen Mirthas
Nyra Quellis

Selene Araveth
PS C:\PXL\Bach>

  • Clear-Host

    Als het PowerShell-terminalvenster vol raakt, kan je het scherm van de shell leegmaken met Clear-Host.

  • Restart-Computer

    Via PowerShell kan je de computer ook herstarten met Restart-Computer.

Cmdlets voor systeemdiagnose¶

  • Get|Stop-Process

    Alle processen die op je systeem draaien, kunnen via PowerShell beheerd worden. Afhankelijk van de actie die je op de processen wil uitvoeren, moet je een ander verb in de cmdlet gebruiken: - Get-Process: geeft een overzicht van de huidige actieve processen op je systeem. - Stop-Process: stopt een bepaald proces op je systeem. Stop-Process -Name msedge stopt alle Edge-processen die momenteel op het systeem draaien.

  • Get|Start|Stop-Service

    Alle services die op je systeem geconfigureerd zijn, kunnen beheerd worden met <Verb>-Service. Met het juiste verb en de juiste parameters kan je de services controleren (als administrator): - Get-Service: geeft een overzicht van alle momenteel geconfigureerde services op je systeem. - Start-Service: start een specifieke service via de parameter -Name. Start-Service -Name XboxNetApiSvc start de Xbox Networking-service op je systeem. - Stop-Service: stopt een specifieke service. Stop-Service -Name XboxNetApiSvc stopt de Xbox Networking-service.

  • Get-EventLog

    Met deze cmdlet kan je zoeken in de Windows-eventlogbestanden. Get-EventLog -LogName System geeft alle System-logs. Met extra parameters kan je de logs verder verfijnen.

  • Get-Disk

Netwerkgerelateerde cmdlets¶

De commando's die in deze paragraaf worden uitgelegd, worden vaak gebruikt door systeem- en netwerkengineers. De meest gebruikte commando's zijn echter geen PowerShell-cmdlets. Het zijn ingebouwde Windows-toepassingen (te vinden in C:\Windows\System32) die afstammen van MS-DOS-batch en nog steeds beschikbaar zijn in PowerShell of Command Prompt. Omdat deze commando's (eigenlijk toepassingen) nog vaak gebruikt worden, leggen we het gebruik ervan uit en geven we ook het juiste PowerShell-alternatief. Beide kunnen gebruikt worden.

    Met dit commando kan je een DNS-lookup uitvoeren (een naam omzetten naar een IP-adres):
